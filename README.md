# 🔴 React

## 🔴 React v2.0 (Simplified)

**Zero friction. Open → 4 actions → tap → escape.**

No state selection. No emoji diagnosis. Just 4 cards with things you've chosen before.

🎲 Don't like them? Reshuffle.
➕ Missing something? Add your own action.

## 🧠 What is this?

You know that feeling when you're stuck in a game, binge-watching YouTube, or just staring at the wall — and your brain is so full of junk that you can't remember a single thing you actually *enjoy* doing?

**React** is the red pill.

It doesn't ask "how are you?"  
It doesn't set reminders.  
It doesn't track your sleep.

It just gives you **4 options**. Things you've chosen before when you felt exactly like this.

👇 Tap an action. The app closes. You go do it.

## 🎲 How it works

1. Open React
2. See 4 action cards
3. Tap 🎲 to reshuffle (no repeats)
4. Tap ➕ to add your own action
5. Tap an action → app closes → you go do it

The more often you choose an action, the more likely it appears next time.  
No questions. No "did it help?" Just frequency. The app learns quietly.

## 📊 Stats & export

Long press anywhere on the main screen → see your top actions.  
Export as JSON + CSV → share to Telegram, email, or analyze with AI.

## 🧠 Philosophy

This app is not a planner. Not a tracker. Not a notification machine.

It's a **lifeline** for the moment your brain freezes.  
The red pill. Choose to wake up. Choose to remember what you love.

## 🛠 Tech

- Kotlin + Jetpack Compose
- Room database (local only)
- Android 13+
- No internet. No accounts. No ads.

## 🤖 How this app was made

This app was designed and built through **vibe coding** — a conversation between a human ([@lexbayart](https://github.com/lexbayart)) and an AI agent.

No Android Studio was manually touched. No Kotlin was handwritten. The entire codebase was generated by an AI agent following a detailed design document shaped over several hours of brainstorming.

### Development environment

- **OS:** macOS (Apple Silicon)
- **Android version:** 13 (API 33)
- **Build tools:** Android Studio (installed, never opened), Gradle 8.7, JDK 17
- **Device:** POCO / Xiaomi (Android 13) with USB debugging
- **AI agent:** Local MLX model + custom prompts

### What the AI did

- Created full project structure
- Wrote all Kotlin + Jetpack Compose code
- Built Room database schema and DAOs
- Implemented weighted random logic
- Added haptics, sounds, dark/light theme
- Fixed compilation errors and layout bugs
- Generated APK, installed on phone, tested
- Created GitHub repo, made it public
- Generated social preview, releases v1.0, v1.1, and v2.0

### What I (the human) did

- Defined the philosophy: "red pill for your brain"
- Specified the 4-card + 🎲 interface
- Rejected features (no notifications, no questions, no timers, no state selection)
- Tested the app, reported bugs, requested fixes
- Designed the app icon (Neo + red pill + Matrix code rain)

### Why this matters

This app proves that **non-developers can build real, useful Android apps** by collaborating with AI. You don't need to know Kotlin, Android Studio, or Room. Just a clear idea and an AI agent that follows instructions.

## 📦 Download & install

**Option 1: Download APK from Releases**

Go to [Releases](https://github.com/lexbayart/React/releases) → download `app-debug.apk` → allow "Install from unknown sources" → open → tap your action → escape.

**Option 2: Build from source**

```bash
git clone https://github.com/lexbayart/React.git
cd React
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

**Requirements:** Android 13+ (API 33)
